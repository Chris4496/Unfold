# WorkBuddy

本資料夾是現行可攜式使用者體驗探索 skill。給任何模型／agent 使用時，先讀本頁，再從 **SKILL.md** 開始，按需讀 references。

流程：agent 讀產品代碼／文件 → 提出使用者 agent 人數、完整背景與情境 → 用戶確認 → 核對執行條件與限制、讓用戶選擇處理方式 → 再確認 → 自然使用模擬 → 觀察與交接分析 → 圓桌／報告 → 最後統一整理獨立 Dashboard。預设不用即時監控 server。

## 給 AI 的讀取範圍

- **archive/ 不要讀取、搜尋、遞迴掃描或作為上下文。** 其中全部是舊版資料，不是現行指令。只有用戶明確指定歷史比較或某個舊檔時，才讀該範圍。
- `test-runs/` 是保留的歷史測試資料。只有本輪需要且用戶指定的 run 才讀，不把它們當成角色答案、不改寫舊結果。
- 讀代碼時將 archive、test-runs 及本工具本身排除在產品來源之外；不要對整個倉庫做包含歷史資料的遞迴全文搜尋。
- `references/` 是現行按需規格，`scripts/` 是可選的離線輔助，`tests/` 只驗證輔助工具，`assets/` 是現行輸出素材。

角色方案與限制處理都須獲得具體人類確認；「完成 evaluation」不代表可以略過。人數只計扮演使用者的角色，不含分析／審核 agents。

## 可攜式分享

見 PORTABLE.md。只分享現行 skill 檔案，排除 archive 及 test-runs。此更新不執行任何 evaluation、不重跑歷史 run。
