# 把此 Skill 交給其他模型／agent

把整個資料夾或 zip 交給執行者，從 `SKILL.md` 開始，按相對路徑讀所需 references。所有規則與程式均在資料夾內，沒有特定模型、Codex 工具、全域設定或 API 金鑰依賴。

可用的起始指令：

> 依此資料夾的 SKILL.md 工作。產品項目是我提供的程式碼與文件。先執行 Agent 1 的唯讀產品分析，完成產品理解、角色、Persona 與生活情境提案，一併交我確認。不要先要求我填產品介紹、客群或研究問題，不跑技術驗證，不修改產品。確認前不啟動使用者模擬。技術來源放附錄，提案主文用非技術語言。

模型自行完成理解與推論。`scripts/agent1.py` 只幫忙整理來源、檢查提案結構，可選用 Python 3.9+；使用標準庫，沒有依賴安裝步驟。材料整理不能被當作分析完成或用戶批准。

Agent 1 需要讀來源的能力；後續 roleplay 需要能操作產品 UI 的環境與獨立身份。沒有子 agent 編排時，可人工轉交角色卡至全新、沒有分析歷史的會話。角色卡不能夾帶源碼、已知問題或預期答案。所有感受標為 AI 角色模擬，不冒充真人回饋。

即時 dashboard 需要執行環境另提供事件服務。本套 Agent 1 改動不包含 dashboard server，亦不自動執行任何 run。`tests/test_agent1.py` 只測輔助程式，不是產品功能測試。
